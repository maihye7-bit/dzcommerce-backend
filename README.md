# DzCommerce

DzCommerce وكيل تجارة إلكترونية مدعوم بالذكاء الاصطناعي وموجّه للسوق الجزائري، مع دعم المحادثة بالعربية والدارجة والفرنسية.

## المزايا

- تجارة محادثية مع فهم طلبات العملاء وحل اختيارات المنتجات والمتغيرات.
- إدارة المنتجات والمخزون ومسودات الطلبات والطلبات.
- لوحة مالك server-rendered على `/dashboard` لمتابعة المنتجات والمخزون والطلبات والمحادثات وإعدادات المتجر.
- عزل متعدد المستأجرين بحسب المتجر.
- تكامل قنوات Meta مع التحقق الأمني من Webhook.
- تتبع استخدام مزود الذكاء الاصطناعي.

## المكدس التقني

- Backend: FastAPI، PostgreSQL، SQLAlchemy، Alembic.
- Agent وLLM: Qwen عبر OpenRouter أو مزود متوافق وفق إعدادات المشروع.
- Admin UI: Jinja2 وHTMX مع CSS خفيف داخل FastAPI.
- Existing frontend: React 18، Vite، TypeScript، TanStack Query، Tailwind CSS، shadcn/ui.

## البدء السريع

راجع [DEPLOYMENT.md](./DEPLOYMENT.md) لإعداد البيئة وقاعدة البيانات وتشغيل Backend وFrontend.

## البنية المعمارية

```text
قنوات Meta / لوحة التحكم
            |
            v
     FastAPI وواجهات API
     /       |        \
Webhook  /dashboard  REST API
     \       |        /
       Conversation Engine
         + Commerce Resolver
         + Agent Tools / Services
                 |
         SQLAlchemy Models
                 |
            PostgreSQL
```

لوحة المالك تستخدم جلسة cookie موقعة وCSRF، وتختار متجر المالك من العضوية
الموثقة في قاعدة البيانات. سجّل الدخول بالبريد الإلكتروني وكلمة مرور الحساب
القائم؛ لا توجد صفحة تسجيل عامة جديدة. في الإنتاج اضبط `JWT_SECRET_KEY` قوية
واتصل عبر HTTPS. بعد ترقية قاعدة البيانات، تُدار معلومات العنوان والتوصيل من
صفحة إعدادات المتجر، ويستخدمها رد معلومات المتجر في المحادثات عند توفرها.

## الاختبارات

آخر تشغيل كامل أثناء إضافة لوحة المالك: 418 اختبارًا ناجحًا. شغّل المجموعة من جذر المشروع:

```powershell
pytest -q
```

## بنية المستودع

- `app/` — تطبيق FastAPI، الوكيل، القنوات، الخدمات، النماذج والمخططات.
- `frontend/` — لوحة التحكم المبنية باستخدام React وVite.
- `scripts/` — أدوات مساعدة لإدارة المشروع وربط الحسابات.
- `tests/` — اختبارات Backend.
- `alembic/` — إعدادات وإصدارات ترحيل قاعدة البيانات.
